# StudioSpace

**Live Site URL:** https://studio-space-woad-eight.vercel.app

## Features of My Website
- Explore different creative studios, including photography studios, film stages, podcast lounges, and music suites.
- View studio details, images, hourly rates, security deposits, and amenities.
- Add, edit, and manage personal studio listings.
- Book studios by selecting preferred dates and times.
- Manage bookings and save favorite studios to Wishlist.

## Technology Stack
- Next.js
- React.js
- TypeScript
- Tailwind CSS
- Express.js
- MongoDB
- JWT & HTTP-only Cookies

## Local Setup Instructions
1. Clone the client and server repositories.
2. Run `npm install` in both folders.
3. Configure the required environment variables (`.env.local` and `.env`).
4. Add your MongoDB connection URI and JWT secret.
5. Start the backend server using `npm run dev`.
6. Start the client using `npm run dev`.
7. Open `https://studio-space-woad-eight.vercel.app` in your browser.
